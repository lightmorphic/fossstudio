Recording quality

What each person's own track holds. It applies to the next recording you start; a take already running keeps the setting it began with.

✓ Saved

A file with .webm on the end is a box, and the name on the box does not tell you what is inside it. The same box holds either every sample your microphone heard or about a twenty-fifth of that, and until you open it in an editor the two look alike. That is the whole of this choice: the box stays the same, the contents do not. Best quality keeps everything, which matters if the recording will be cleaned up, levelled or repaired afterwards. Smaller files throws away what the ear does not miss on speech, and a two-hour show with four people becomes a few hundred megabytes instead of eleven gigabytes.

Firefox cannot record uncompressed audio at all. A guest on Firefox comes back compressed whatever this is set to, and the Recordings list says so beside their track. More about what is in the file

Your account

The studio's one login. Your sessions, recordings and settings are all under it.

Account name

The name for this account - it's also what you sign in with. Rename it any time, e.g. if you switch to a different podcast. Lowercase letters, numbers, - or _, 2 to 24 characters.

✓ Saved

Change your password

At least twelve characters, and not one of the passwords everybody guesses first. There are no rules about capitals and symbols; length is what makes a password hard to guess. If HOST_PASSWORD is still filled in in your compose file, the next restart puts that one back - empty it there and the password lives here instead. More about the login

Passkeys

Your browser or phone keeps the key and this studio only stores the public half, so a stolen copy of the data folder gives nobody a way in. A passkey belongs to the address you made it on: move the studio to a different domain and it stops working, which is why the password above stays as the way back. More about the login

Studio address

Both of these used to be lines in a compose file. They take effect when the studio restarts.

The address people type to reach the studio, and the one its certificate is fetched for. Why HTTPS is not optional

Audio and video go straight between browsers and this machine rather than through the web server, so the studio has to tell every guest which address to send them to. Get it wrong and the room opens and stays silent. Find it with curl -4 https://api.ipify.org on the machine. More about this

Only needed when the domain above does not reach this machine directly - a proxied Cloudflare record or a tunnel. Relay traffic has to arrive here, so put an unproxied name or the raw address.
