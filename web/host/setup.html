This studio has no owner yet, so it is yours to claim. Set a password and it is.

Choose how you will get back in. You can add a passkey in a moment; the password is what saves you if you ever lose it.

At least twelve characters. There are no rules about capitals and symbols - they produce Password1! and help nobody. Length is what makes a password hard to guess.

Add a passkey? Your browser keeps the key and the studio only stores the public half, so a stolen copy of the data folder gives an attacker nothing they can log in with. There is no password to phish, either.

A passkey belongs to the address you made it on. Move the studio to a different domain and it stops working - which is why the password you just set stays as the way back in.

Turn on two-factor? A code from an app on your phone, on top of the password. It is worth the minute now; nobody comes back to do it later.

Add this secret to your authenticator app - 1Password, Aegis, Google Authenticator, whatever you use. On a phone, the link opens the app directly.

The address people type to reach the studio. Why HTTPS is not optional

Audio and video go straight between browsers and this machine, not through the web server, so the studio has to tell every guest which address to send them to. Get it wrong and the room opens and stays silent. Find it by running curl -4 https://api.ipify.org on the machine. More about this
