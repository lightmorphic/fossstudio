What this covers - and what it doesn't

This notice covers this website only. Hosting

The site is served by GitHub Pages. Like any web host, GitHub keeps standard server logs (your IP address, the page requested, the time) to run and protect the service - that's covered by the GitHub privacy statement. We don't receive or look at those logs.

Your rights

UK data-protection law gives you rights over personal data an organisation holds about you. We don't hold any from your visit here, but if you believe otherwise, or have any question at all, email us and we'll answer plainly. You can also complain to the Information Commissioner's Office.
