Complaints

If something's wrong, we'd rather hear it plainly than not hear it at all. One thing to know first: FOSSStudio is a free, open-source project provided "as is" - there's no paid service behind it and no guaranteed response times, just people who care about it.

About this website or the software

Email complaints@lightmorphic.com with what happened and, if you can, a link or screenshot. A person reads every message and answers as time allows - honestly, if not always quickly. Bugs and security reports are also welcome on GitHub - security issues by email first, please, so a fix can land before the details are public.

About a show or studio someone runs

Every FOSSStudio installation is run independently by its own operator, on their own server. If your complaint is about the content of a particular show, stream or chat, it belongs with the person running that studio - we have no access to their server and can't remove anything from it. If you believe the software itself is being used unlawfully, tell us anyway; we'll do what's actually in our power.

If you're not happy with our answer

Write to Lightmorphic Ltd, 82A James Carter Road, Mildenhall, IP28 7DE, marking it for the director's attention. Complaints about how personal data has been handled can also go to the Information Commissioner's Office.
